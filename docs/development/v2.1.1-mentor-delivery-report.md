# v2.1.1 Mentor Delivery Report

## Baseline

The starting point was v2.1.0:

- `pytest`: 20 passed, 1 skipped.
- HY V3 example already had four high-density pages and complete class/method review.
- Confirmed issue: `examples/hy_v3` stored developer-machine absolute paths, so evidence validation could fail after relocation.

## Confirmed Problems

1. Golden Example was not portable because JSON artifacts contained absolute paths.
2. `report.md` claimed validation passed even though relocated validation could fail.
3. Method importance was too aggressive; simple delegates were classified as core.
4. Weight mapping catalog emitted raw low-level events instead of architecture-level mapping groups.
5. `embed_input_ids` incorrectly triggered pooling capability.
6. Some HY V3 diagram details were semantically or visually ambiguous.

## Path Portability

Added `src/vllm_architecture_agent/paths.py` for repo-root inference and portable path handling.

Repository-internal artifact paths are now written as repo-relative strings such as:

```text
samples/hy_v3.py
```

`vllm-arch validate` accepts `--repo-root` and validators resolve context, plan, evidence and image paths through the same helper functions.

## Collector Precision

Method importance:

- Removed `embed_input_ids` from core method names.
- Added simple delegate detection.
- Kept `compute_logits` as core because it defines the output/logits boundary.

Mapping groups:

- Raw mapping-like events are grouped into architecture-level items.
- HY V3 now reports 12 mapping groups instead of 69 raw events.
- Groups include event counts and evidence ranges.

Capability detection:

- `embed_input_ids` no longer triggers pooling.
- FusedMoE alone no longer proves Expert Parallel.
- Generic `attn` variable names no longer prove custom attention.

## HY V3 Diagram Fixes

Page 1:

- PP first-rank and non-first-rank inputs are now shown as mutually exclusive entry modes.
- Component composition has containment edges.
- Optional tied embedding weight is visible as a dashed dependency.

Page 2:

- Added explicit residual bus with two RMSNorm handoffs.
- HPC path shows `qkv -> HpcRopeNorm -> vLLM Attention`.
- Added KV cache write and external read boundary.
- V bypasses Q/K norm.

Page 3:

- Removed duplicate GateLinear semantics.
- Linked runtime FusedMoE to the external fused runtime boundary.
- Linked EP metadata to expert placement/FusedMoE boundary.

Page 4:

- Removed development wording about missing LoRA checkpoint edge.
- Rewrote TP/PP/EP panels as structured summaries.
- Kept wrapper and model weight loading as separate lanes.

## Current Limitations

- Draw.io layout is Agent-designed, not pixel-deterministic.
- The validators do not perform deep image recognition.
