# v2.1.2 中文导师易用版开发报告

## 1. 版本目标

v2.1.2 基于 v2.1.1 Mentor Delivery Release 做最后一轮中文交付收敛。本次不修改源码分析、Architecture Plan、Evidence、Draw.io MCP 或完整性验证的总体架构，也不恢复旧 IR、Concept Graph、View Graph 或确定性 renderer。

本次目标是让导师在另一台电脑上更容易安装、理解和使用项目：

- README 首屏直接给出安装和一句话启动方式；
- 导师直接阅读的文档中文化；
- 新增 `tools/setup-mentor.ps1`；
- 明确 Draw.io MCP 配置和 VS Code Codex 重启步骤；
- 解释输出文件；
- 补充其他模型分析方式和常见故障排查；
- 重新构建 mentor zip。

## 2. 保持的架构原则

默认工作流仍然是 Agent-native：

```text
Target Python file / Registry architecture
  -> resolve_model_target.py
  -> collect_source_context.py
  -> source-context.json
  -> Codex 完整源码审阅
  -> architecture-plan.json + evidence.json
  -> validate_architecture_plan.py + validate_evidence.py
  -> Draw.io MCP 绘图和视觉复查
  -> validate_drawio.py
  -> architecture.drawio + PNG + report.md
```

本轮没有新增：

- Source Fact Graph；
- Semantic Inventory；
- Architecture IR；
- Architecture Design/View Graph；
- Layout Plan；
- Review Patch/Lock；
- 确定性 Draw.io Renderer；
- 模型专用模板。

## 4. 导师安装脚本

新增通用入口 `tools/setup.ps1`，并保留 `tools/setup-mentor.ps1` 作为兼容安装实现。

功能：

- 检查 Python；
- 执行 `python -m pip install -e ".[dev]"`；
- 创建 `.agents/skills/vllm-model-architecture-diagram` 到 canonical Skill 的 Junction；
- 在传入 `-ConfigureDrawioMcp` 时写入 `[mcp_servers.drawio]`；
- 不重复写入已有 Draw.io MCP 配置；
- 打印 `codex mcp list` 和一句话启动指令。

保留 `tools/setup-codex-dev.ps1` 作为开发者脚本，但修复了之前的中文乱码。

## 9. 当前限制

- 真实 vLLM 全目录 scan 仍依赖本地 vLLM checkout。本轮不下载或克隆外部仓库。
- Draw.io 图仍由 Codex 和 MCP 完成，语义优先于像素级确定性。
- External runtime internals 仍按 evidence policy 标记为 external，除非 Codex 明确读取相关源码。
